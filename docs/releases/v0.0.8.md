# metadata-gen 0.0.8

The hand-written part of the release notes. The release workflow reads
everything from `## Highlights` down and composes What's Changed, the
checksums and the Full Changelog line around it.

## Highlights ⭐️

* **RUSTSEC-2026-0333 is fixed**: `noyalib` moves to 0.0.56, and every front-matter parse runs under `ParseLimits` with the YAML parser's strict budgets, on the typed path as well as the flat one.
* **Pay only for the formats you parse**: `yaml`, `toml`, `json`, `html` and `tokio` are Cargo features, all on by default, and `default-features = false` builds a `no_std + alloc` core.
* **Errors that point at the fault**: a parser's rejection is `MetadataError::Parse` with the format, the byte span and the parser's own message, and an unclosed fence reports its byte offset.
* **Spec-correct meta tags, with breaking output changes**: Open Graph tags use `property=`, attribute values escape `&`, `<` and `>`, and slugs keep letters and digits only; `docs/MIGRATION.md` lists every change.
