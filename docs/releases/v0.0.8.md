# metadata-gen 0.0.8

The hand-written part of the release notes. The release workflow reads
everything from `## Highlights` down and composes What's Changed, the
checksums and the Full Changelog line around it.

## Highlights ⭐️

* **TOML front matter without colons is accepted**: `extract_and_prepare_metadata` no longer rejects a valid `key = "value"` block that happens to contain no `:`.
* **Verification suites join the gate**: proptest round-trips for YAML, TOML and JSON, a Loom smoke test, Kani proofs for `escape_html`, and a cargo-mutants configuration.
* **Release and supply-chain automation**: a tag-driven release workflow with build provenance and a CycloneDX SBOM, every action pinned by SHA, OpenSSF Scorecard, and MSRV, API-breakage, feature-powerset, complexity and link gates in CI.
* **In lockstep with noyalib 0.0.43**: the first-party pin moves with a cargo-vet publisher attestation.
