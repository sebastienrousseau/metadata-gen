# metadata-gen 0.0.9

The hand-written part of the release notes. The release workflow reads
everything from `## Highlights` down and composes What's Changed, the
checksums and the Full Changelog line around it.

## Highlights ⭐️

* **`oxml` replaces `quick-xml` for `<meta>` extraction**: `extract_meta_tags` and `extract_meta_tags_lenient` (feature `html`) now scan `<meta>` tags with `memchr` and parse attributes and entity references with `oxml = "=0.0.13"`, removing `quick-xml` from the dependency graph.
* **MSRV raised to Rust 1.89.0**: `rust-version` in `Cargo.toml`, the `msrv` CI job, and all documentation now enforce Rust 1.89.0, aligned across the maintainer's Rust crates.
* **Dependency and security updates**: bumps `noyalib` to `=0.0.58`, `tokio` to `1.53.3` (clearing `RUSTSEC-2026-0386`), and `toml` to `1.1.8`, with full `cargo-vet` provenance and reduced exemption count.
